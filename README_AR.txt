Qureo Solver Tool — النسخة النهائية
====================================

التشغيل على ويندوز
------------------
1) تأكد أن Python 3 مثبت ومضاف إلى PATH.
2) شغّل run_ui_windows.bat.
3) افتح الرابط الذي يظهر في النافذة، ثم سجّل الدخول واختر المسار والفصول.

التشغيل على Termux
------------------
1) ثبّت Python.
2) شغّل: bash run_ui_termux.sh
3) افتح الرابط المحلي الظاهر في الطرفية.
   مسار الثقافة المالية غير مدعوم على Termux لأنه يحتاج Google Chrome الكامل.

ما تم إصلاحه
------------
- قراءة بيانات الفصول تدعم الشكلين المسجلين من QUREO، بما فيه غلاف section؛
  كما تبحث بصورة متحفظة داخل الأغلفة الجديدة عن صفوف الفصول الصحيحة فقط؛
  هذا يعالج خطأ «رد القسم لا يحتوي على قائمة chapters متوقعة» لمساري JavaScript وPython.
- ملفات answers_json/ هي المصدر الأساسي للإجابات، مع إبقاء answers/*.txt نسخة احتياطية.
- تم اعتماد التصحيح المرسل لفصل JavaScript 18.
- تم إصلاح مطابقة اختيارات HTML مثل <p> و<img>، وإرسال الكود المكتمل في أسئلة ملء الفراغات كما ظهر في التسجيلات.
- تم تصحيح الإجابات المتحقق منها في تسجيل Python للفصل الأول.
- تضمين Playwright ضمن تثبيت واجهة ويندوز حتى يظهر مسار الثقافة المالية جاهزًا عند وجود Google Chrome.

ملاحظات مهمة
------------
- الأداة تتوقف ولا تخمّن عند سؤال غير مطابق أو عندما يرفض الخادم إجابة.
- إذا تغيّر رد QUREO جذريًا، تُنشئ الأداة data/runtime_section_shape.json بلا بيانات دخول؛
  أرسل هذا الملف فقط عند طلب الدعم.
- لا تحفظ كلمة المرور داخل المشروع؛ لا ترفع ملفات data/ الناتجة عن التشغيل.
- ملفات تسجيل HAR الأصلية لم تُضمّن في النسخة النهائية لأنها قد تحتوي جلسات أو بيانات حساسة.
- الثقافة المالية تعمل عبر Google Chrome المثبّت محليًا؛ وإذا كان في مسار غير معتاد عيّن CHROME_PATH لمسار chrome.exe.
