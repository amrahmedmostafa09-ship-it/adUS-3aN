Qureo Solver Tool — الواجهة (v7.8)
==================================
التشغيل
  ويندوز:  دبل كليك على run_ui_windows.bat
  تيرمكس:  bash run_ui_termux.sh
  أو يدويًا:  python server.py

الموقع يعمل عبر جلسة Cookie آمنة لكل متصفح؛ افتح الرابط العام مباشرة بدون رمز في الرابط.
الخادم يعزل كل جلسة في عامل مستقل، ويسمح لأكثر من مستخدم بالحل في الوقت نفسه.
في الإنتاج يُتحقق من أن المستخدم داخل مصر عبر IPInfo قبل بدء الحل.

الصفحات
  1) اختيار السنة: أولى بكالوريا / تانية بكالوريا.
  2) تسجيل الدخول واختيار المهمة:
       أولى بكالوريا  = حل جافاسكريبت (42 فصل) فقط.
       تانية بكالوريا = حل جافاسكريبت + حل بايثون + حل الثقافة المالية.
     ثم Login ID وكلمة المرور ونطاق الفصول (من/إلى، أو «كل الفصول») وزر «ابدأ الحل الآن».
     الأداة تحل الفصول المحددة بالترتيب (خيار واحد، بدون أوضاع).
  3) مركز التقدم: الحالة، فصول مكتملة، آخر فصل، إجابات مرسلة، شريط التقدم، النشاط المباشر، قائمة الفصول مع سبب أي فصل لم يكتمل.
     زر «إيقاف» يوقف عند أقرب نقطة آمنة؛ و«رجوع» بعد الانتهاء.

الحالة الحالية
  جافاسكريبت: أولى بكالوريا = الفصول 1–42، تانية بكالوريا = الفصول 1–54.
  بايثون (تانية بكالوريا): 25 فصل، كورس python_short_ar وسكشن 106 على بوابة كيريو.
  الإجابات: ملفات answers_json/javascript/chapter_NN.json (54 ملف) وanswers_json/python/chapter_NN.json (25 ملف) هي المصدر
     الأساسي لجافاسكريبت وبايثون؛ وملفات answers/*.txt تبقى نسخة احتياطية متوافقة لو غاب ملف JSON أو تلف. الأداة تطابق كل سؤال حي بنصه ببند واحد فقط، ولو الجواب غير واضح تقف عند السؤال وتكتب
     ملف تشخيص (data/assessment_<الفصل>_unresolved_<السؤال>.json) وتكمل بالفصل التالي. لا تخمين.
     ملفات الإجابات للقراءة فقط؛ لتحديثها استبدل ملف JSON الموافق داخل answers_json/، واترك ملف TXT الاحتياطي كما هو.
  الثقافة المالية (تانية بكالوريا): مفعّل. يشغّل financial/financial_literacy_.py (Playwright + answers.json، المستويات 1–22)
     في الخلفية باستخدام جوجل كروم العادي المثبّت على الجهاز (مش كروميوم، ومفيش تنزيل متصفح).
     محتاج فقط:  pip install -r requirements_financial.txt   + جوجل كروم مثبّت. ملف تشغيل واجهة ويندوز يثبّت المتطلبين تلقائيًا.
     لو كروم في مكان غير معتاد: عيّن المتغير CHROME_PATH لمسار chrome.exe.
     يعمل على ويندوز/ماك/لينكس؛ لا يعمل على تيرمكس. الموقع بيكمّل من المكان اللي وصله الطالب،
     وحقل «حتى مستوى» بيحدد أين يقف. بيانات الدخول بتتبعت للسكربت بمتغيرات بيئة فقط.

الأمان
  كلمة المرور تُمسح من الصفحة فور البدء وتبقى في الذاكرة طوال التشغيل فقط؛ لا تُكتب في ملف ولا تظهر في السجل.
  كل متصفح له تشغيل مستقل؛ لا يشارك المستخدمون RUN_STATE أو STOP_EVENT أو بيانات الدخول.
